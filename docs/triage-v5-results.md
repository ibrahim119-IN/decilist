أُعيد التحقق محليًا من الحالات الـ14: المصدر السليم ينجح، والعيب المزروع يفشل، والإصلاح المرجعي ينجح؛ حالة c01 سليمة أصلًا. اجتازت مجموعة الاختبارات القديمة 985 اختبارًا، وتلتها مجموعات مركزة لتغييرات V5، آخرها 285 لفلاتر الفرضيات والتكامل و26 للمختبر. اجتازت اختبارات JavaScript البناء و22 اختبارًا، ومرّت مقارنة العقود العشرة بين Python وTypeScript وبناء حزمة Python.

تشغيل GitHub للنسخة المثبتة أعطى **1262 ناجحًا وفشلًا واحدًا**: دليل التحقق المحلي المثبت لم يكن متاحًا في نسخة جديدة على Ubuntu، وأُلغي ذراع Windows. لا نعرض التشغيل ده باعتباره ناجحًا. معالجة نقل دليل التحقق إلى النسخ الجديدة مستقلة عن نتائج الموديل المثبتة؛ لم تتغير اختبارات الحالات أو نتائجها لتجاوز الفشل.

أُضيف أمر استعادة يحفظ نفس بايتات الدليل وبصماته، ويرفض استبدال أي ملف مختلف. شغّله CI قبل مجموعة الاختبارات الكاملة. تحقق محلي جديد في مجلد فارغ نجح: **17 اختبارًا للاستعادة و26 اختبارًا أصليًا للمختبر**، مع مطابقة الملفات الخمسة للأصول. ده تحقق محلي؛ حالة تشغيل GitHub اللاحق تُراجع منفصلة.

محاولات التطوير السابقة محفوظة في [سجل التطوير](../reports/triage-v5-development-ledger-2026-10-26.json): ثلاث إعادات لحالات V4 المكشوفة وثلاث جولات لحالتي تطوير V5. ليست حالات جديدة ولا تدخل في نسبة التقييم.

الخطوة التالية هي استكمال سياق تهيئة حالة الكائنات باعتماد مصدر واضح، ثم مقارنة نفس التصميم بين النموذج الحالي ونموذج محلي أقوى على حالات جديدة مثبتة قبل الاختبار. أي إعادة على حالات V5 أصبحت تطويرًا، وليست تقييمًا جديدًا. تجربة المطورين البشرية لم تُنفذ بعد، والمشروع لم يصل بعد إلى ادعاء توفير وقت مثبت للمطور.
